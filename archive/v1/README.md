# Crypto Scanner V1 — history record

**Status: DISCONTINUED / SUPERSEDED**  
**Artifact state: SOURCE ARTIFACT NOT RECOVERED — HISTORY ONLY**

V1 used Binance public read-only market data and examined BTC across 1D, 4H, 1H and 15M timeframes.

Recorded components included:
- EMA50 / EMA200,
- RSI,
- ATR,
- crude min/max support and resistance,
- naive fair-value-gap detection,
- a 20-bar liquidity-sweep concept,
- dashboard-style analysis rather than a validated trade signal.

The historical conclusion was that V1 was not signal-ready. The exact source package was not recovered, so no code is reconstructed here.
