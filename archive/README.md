## Archive rules

- Historical facts are preserved even when the result is negative.
- Missing source is not recreated from memory.
- Passing unit/regression tests are not treated as evidence of trading edge.
- A version that cannot prove leakage-safe, cost-aware positive expectancy remains discontinued.
- This repository makes no claim of validated alpha or production readiness.
