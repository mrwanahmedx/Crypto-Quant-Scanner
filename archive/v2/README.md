# Crypto Scanner V2 — history record

**Status: DISCONTINUED / SUPERSEDED**  
**Artifact state: SOURCE ARTIFACT NOT RECOVERED — HISTORY ONLY**

V2 expanded the Binance Spot long-only scanner into a multi-coin framework.

Recorded additions:
- fractal HH/HL/LH/LL structure,
- EMA50 / EMA200 and RSI,
- clustered support/resistance,
- displacement/ATR/trend-filtered FVG logic,
- liquidity-sweep detection,
- an arbitrary 10-point signal score,
- watchlist including BTC, ETH, SOL, SUI, LINK, AVAX, AAVE and INJ.

Synthetic tests passed the implementation mechanics, but the score weights were not empirically derived. That meant the version had no defensible evidence that its ranking represented real predictive edge.

It was superseded rather than promoted. The exact source package was not recovered and is not reconstructed here.
